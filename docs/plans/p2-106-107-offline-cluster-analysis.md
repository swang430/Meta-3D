# 4×2 传导信道的离线核验设计

两项均为信道工作台的辅助分析。操作员在信道工作台的“查看或核验已有工程”中主动发起分析。Meta-3D 负责读取输入、核对来源和展示结果；ChannelEngine 负责只读数值分析。分析输出单独保存，不回写成员表、ASC、工程参数或执行资格。未发起、分析失败、有警告或仅部分可核验时，原有导入、生成和执行均可独立使用。

## P2-106　其他端口的成员分组有多少依据

使用 RT-IMT-2030 下行 MPDB、同源成员表和可核对的分组说明。先按文件摘要、帧、阵元对、链路号、射线行顺序及有效行筛选规则对齐。历史成员表可以作为被分析数据；其产生工具不构成运行依赖。两项分析及验收均不得导入、启动或调用 HyperRT，也不以补算成员表为前置。缺少同源成员、行次序或方法依据时列明缺项。时延分箱的结果只按其分箱定义核对，不能据此确认角度匹配。

对参考端口和其余七路分别报告覆盖。逐射线比较时延及收发方向，用单位方向向量的夹角处理方位角绕回及极点。分别列出已分配簇和其他候选簇的最近参考成员、各维差值及候选是否可区分。距离量纲、归一尺度及容差须记录来源；无依据时保留原始差值。分析采用的距离可能与原分配方法不同，候选排名变化仅作观察。按帧、发收端口、簇汇总射线数和非相干功率占比，保留源行定位。共享标签仅说明分组关系，不证明跨端口或跨帧物理路径身份。

结果分项呈现。可复算的成员计数或复系数与同源工程记录矛盾时警告，附预期值、实得值、容差及定位。候选并列、参考端口缺少对应射线或缺乏物理身份依据时标明“未核验”，说明覆盖比例。来源冲突可告知文件不匹配，停止该项计算，工程仍可使用。验收使用原样数据如实出结果，再在副本中移动一条对复系数有可辨贡献的射线，保留原成员汇总作独立依据，验证能定位受影响的簇；另验绕回、并列和缺成员三种情况。

## P2-107　相同成员使用两种时延时会差多少

固定同一帧的成员、各端口复系数、源帧、频率网格和相位参考，只替换簇时延。方案 A 对各端口各簇按成员的 |H|² 加权平均时延；方案 B 对该帧同簇八路所有成员按 |H|² 合并加权，得到共享时延。报告注明强端口权重更高。空簇贡献为零；成员缺失或数据归属不明的链路标明未核验。

原始参考由每条射线的载频复系数 h 和时延 τ 直接计算：H(Δf) = Σ h exp(−j2πΔfτ)。两种压缩方案将同簇复系数相加后代入同一表达式。Δf 为相对载频的偏移，避免重复计入载频相位。频点包含中心和带边，记录带宽、来源、步长和点数。没有可核对带宽时仅可使用明确标注的分析频段。载频处两种方案应与原始相干和在数值误差内一致；区分方案主要看带内非零偏移。

逐帧逐频点对照八条链路的复数误差、整矩阵归一化平方误差；固定接收端比较各对发射端，固定发射端比较两接收端。相位用两端口响应乘共轭取角，再与原始相位差作环绕比较。任一端在参考或待比较方案中低于明示的幅度可信下限，该点相位标为未核验；没有可靠下限时不出相位通过判词。记录有效点数量、占比、误差分位数及最差帧、端口对和频点。参考能量为零时给绝对误差。没有预定工程容差即只报告差值，不自动选方案或更新默认生成方式。

验收先用可手算的双路径例核对符号、频偏、相位绕回和幅度零点，再用本批全部 38 个源帧、每帧八路运行。保存输入摘要、分析参数、两方案逐项结果和缺证原因。用副本改变一个已知簇时延，应能看到载频复系数不变、非零频偏的误差改变。以无 HyperRT 环境完成两项分析，并检查分析前后工程文件摘要一致。离线复算结果仅说明数值重建误差。

## Lauraycs 后续导出需求（独立跟踪）

优先导出逐帧物理时间、单位及时间原点；射线在本帧的稳定索引，以及可保证的跨帧或跨端口路径标识与有效范围。若无法保证路径身份，可提供有序交互类型、几何对象或面编号、交互位置与坐标系供比对。已有原生聚簇可附逐射线成员映射、标签作用域、端口和帧映射、零值筛选与排序规则、算法版本及随机种子（如适用）、关联置信依据。当前两项开发均可在这些字段缺失时给出范围受限的分析，本轮不修改 Lauraycs。

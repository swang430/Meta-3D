状态：2026-11-14用户批准离线评估方案；正式接入另审，尚未宣布多快照可执行。

**目标：** 用同一份原始多径评价现有算法的损失，依据用途选择正式接入路线。
**结构：** 先完成独立离线评估，再依据评估结果制定正式接入变更。输入适配、算法输出、评价结果分开保存；不把统计表示伪装成确定性复响应。
**实现环境：** 现有Python、NumPy、Pydantic及Lauraycs聚簇依赖；不新增仪器命令、不修改HyperRT。

## 1. 本次核实的事实

- Meta-3D基线`a4de07e0`，ChannelEgine基线`1ba1130d`，Lauraycs基线`53ea4cf9`。本机源码版本不代表已部署版本。
- 输入复用S5a的`s5-raw-paths/1`；上下行各38帧，用户速度5m/s，坐标米制仍为显式假设。非均匀时间跨度约36.174939秒，不能换成38个等间隔时刻。
- `ChannelEgine/mimo_ota_simulator/geometric_native_fit.py::geometric_native_fit`是现有单帧入口，输入MPC包含功率、时延、角度、可选相位；统计聚簇不使用相位，输出子径也不保留原时延和相位，不能据此重建原始复频响。
- `spatiotemporal_tracking.py::native_fit_trajectory`仅声明统一`skeleton_rate_hz`，当前不能承载本次逐帧时刻。
- `Lauraycs-source/webService/app/services/channel_analysis/clustering.py::_cluster_cdl_udf_result`调用既有`CLUSTER_CDL`，返回复响应、时延和角度；会过滤非正功率或字段不全路径，必须对过滤量留痕。其固定随机种子不能替代版本记录。
- 原生射线生成测试此前被过期许可证阻止。不能据此断言所有离线聚簇也不能运行：先核依赖并正常调用，失败如实记录，禁止替换算法或绕许可。
- 正式拒绝点仍在`api-service/app/services/mimo_ota/channel_asset_resolver.py::resolve_channel_asset`相关多快照分支；本次评估不改变它。

## 2. 推荐先交付的评估范围

作为原S5c的第一步，不另建重复待办编号。先做逐帧评估，不把缺少物理路径身份的插值视作真实帧间轨迹。

1. 校验原ZIP、适配文件及算法源码SHA256；原文件只读，结果写独立目录。
2. 上下行分别处理全部38帧。以同一帧的原始路径分别调用两套现有算法，不串联两次聚簇。
3. 建议初始最大簇数为8、16、24，用作离线精度曲线，不声明它们是仪器能力。记录请求上限、实际簇数、过滤路径数及过滤功率；超上限标记失败，不能截断结果凑数。
4. 每次调用记录时刻、单位解释、角度转换、速度向量及来源。CE计算多普勒所需方向不能只由“5m/s”推断；运动端、坐标差分与角度坐标约定核清是整帧CE聚簇评估的前置条件。其多普勒拟合会影响簇分裂及成员，不能仅停用多普勒指标后继续将时延、角度误差当作有效结果。前置未满足则保留整帧并标不可评价；若做假设方向的敏感性实验，整份输出均注明假设，不用于正式路线选择。
5. 输出每帧绝对量和归一化量，汇总最差帧与分布；不只报一个平均分掩盖局部失真。

原始H使用复数实部/虚部；功率为`abs(H)**2`，相位由H计算。原始PHASE列若为复因子不得当弧度。单位转换必须有显式解释和来源，不能靠字段名猜测。全零功率、非法字段、被算法过滤或无法执行的帧均保留状态，不从分母中消失。

## 3. 比较什么、不比较什么

| 内容 | 方法 | 可解释范围 |
|---|---|---|
| 能量变化 | 分别记录输入与输出的功率和、比值；零分母标不可评价 | 相干合并可能相消，差值本身不直接判算法错误 |
| 时延分布 | 功率加权平均时延、均方根时延扩展及分布距离 | 原始单位解释成立条件下的压缩损失 |
| 角度分布 | 方位角用圆统计；天顶角与方位角分开；相同角度约定 | 圆均值不存在时保留未知，不硬算0度 |
| 复频响 | 对保留复响应的输出，在显式频率偏移网格上比较`sum(H*exp(-j*2*pi*df*delay))`，记录绝对与归一化误差 | CE当前统计聚簇无相位，填不可评价；单载频射线的网格扩展是模型诊断，不等于实测宽带真值 |
| 多普勒 | 区分原始记录、速度角度模型计算、缺失及估计 | 来源或方向未确认不作一致性结论；不把缺失补0 |
| 跨帧变化 | 原始采样时刻的上述量随时间变化；另用已知身份合成例验证关联 | 不从约1秒级采样直接FFT推断完整快衰落谱，不声称恢复帧间物理信息 |

这一步输出误差和适用性，不自动输出“通过”。用途容限尚未定：统计吞吐评价与确定性相位重建不能共用一个阈值。建议先取得误差曲线，再由目标用途明确可接受范围；容限未冻结不开放正式执行。

## 4. 文件与实施步骤

拟新增（尚未存在）：
- `scripts/s5_evaluation/README.md`：固定版本、依赖、输入与复算命令。
- `scripts/s5_evaluation/run.py`：校验及调用调度；不复制聚簇算法。
- `scripts/s5_evaluation/ce_adapter.py`、`lr_adapter.py`：两个独立现有算法入口的字段适配。
- `scripts/s5_evaluation/metrics.py`：独立计算评价指标，不依赖算法内部“相似度”作为唯一证据。
- `scripts/s5_evaluation/tests/test_metrics.py`、`test_adapters.py`：合成已知参考及真实入口行为测试。

输出拟为`ce-clusters.json`、`lr-clusters.json`、`evaluation.json`及`manifest.json`，仅作为离线研究格式，不能直接交正式执行器。共同封套保存输入hash、版本、参数、方向、原帧ID、时间、原始/保留/过滤数量、未知项、运行失败及算法原始结果；不强行把两种内部结构压成丢字段的同一种簇。

实施顺序：
1. 先写独立指标的红测试：完全一致、相消、零功率、角度跨±180度、非有限值、不可评价分支；实现后跑绿。
2. 写两个适配器的入口测试：真实现有函数、明确单位转换、38帧顺序、缺失保持、上限与实际簇数。不能通过mock算法返回固定结果证明能力。
3. 用已知单径/双径合成例核字段和指标；实际依赖无法加载时记录阻塞，不退回另写算法。
4. 对原样本上下行各38帧、三个预算逐项运行，保存结果；正式执行、设备连接均不调用。
5. 核心逆变异至少覆盖时间偷换为等间隔、复相位丢弃、失败帧静默丢弃，确认对应测试失败后精确恢复。
6. 独立内审、相关回归及全评估测试、实际结果复算，再按仓库当前外审流程合并。只有离线脚本不触发后端全量；若改变共享生产行为须重新判档。

## 5. 正式接入的后续设计条件

评价完成后才选择统计或确定性路线，不能预先承诺当前CE统计输出满足相位重建。
正式接入须枚举资产schema与校验、GUI导入及编辑、resolver、prepare、计算服务请求/响应、缓存键、报告来源及历史读取全部消费者；先核非均匀时间在每层的可表达性，再决定最小改动。
只有正确时间轴、缺失语义、用途容限和来源状态可贯通，才考虑收窄正式拒绝条件。不得只删除拒绝语句。

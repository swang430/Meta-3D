# P2-109 前端接口

实现目录 /private/tmp/p2109-vrt。复用 P2-108 上传及下载模式。

POST `/api/v1/channel-assets/mpdb-projects/budget-comparisons`，multipart：
- archive：原始 MPDB 外层 ZIP，根目录 R0B0S0D.mpdb，≤256 MiB。
- members：同源 members.npz，≤32 MiB。保持源行筛选非零 H 后的固定成员，禁止重新聚簇。
- bandwidth_mhz 默认100（0<值≤10000）；points 默认41（3..257奇数）；amplitude_floor 默认1e-8（有限正数）。
- 不需要 ASC。与 P2-108 共用原始 MPDB、成员、频点和幅度下限。38帧全部计算（0..37），P2-108未恢复的末帧不影响此处源帧比较。

200 JSON：schema `mpdb-budget/1`；comparison_id；download_url（report.zip）；points_url（points.csv）。链接已含 /api/v1。
status/alignment_status=`unverified`，formal_verdict=null，simulated=false，hardware_verified=false，不能呈现正式通过。
source.archive/members、mpdb_sha256 为 SHA256；carrier_hz、polarization=H（原始复系数列名，不证明水平极化）；offsets_hz、amplitude_floor、port_order、port_pairs；frame_ids、source_frame_count。
固定 tap_budgets=[24,26,31]；strategies=[independent,shared]，分别表示端口独立功率加权时延、八路共享功率加权时延。

summary 的键为 independent-24/26/31、shared-24/26/31：
- tap_budget 为上限；used_taps_min/max 为跨全部帧端口的实际使用范围，不能当作每路必用预算数。
- matrix_nmse_median、matrix_nmse_p95（线性比值）；phase_error_p95_deg（角度）；无有效值时 null，禁止填0。
- common_valid、improved、worse、unchanged：各策略与自身未拆簇基线（本批为24抽头）在共同有效相位点上比较，容差1e-7度。可显示局部变差，不能宣称增预算必然改善。

ZIP 含 summary.json/report.json/points.csv。
report.json 的 frames 每项含 frame、used_taps（每方法八端口实际数）、ranking（两策略各自的簇排序、分界、单簇带内平方误差、八路新增实际数）、methods（CE逐频点矩阵NMSE、逐端口对相位误差）、coverage、carrier_max_absolute_error、时间及零点依据。
分拆排序依据每帧八路的单簇带内复频响平方误差；每簇最多拆一次；预算B取排名前B减共同簇数个可拆簇（本批共同簇数为24）。八路共用同一早晚分界，系数为原端口成员相干和。预算是上限，稀疏端口不补齐计数。

CSV列：frame,strategy,tap_budget,used_taps_a,used_taps_b,offset_hz,port_a,port_b,matrix_nmse,matrix_delta,phase_error_deg,phase_delta_deg,change,phase_valid,alignment_status,formal_verdict。
port_a/b为 port_order 的索引。delta=CE当前候选减同策略未拆簇基线值（本批24簇时等于24抽头方案），负为改善。change=improved/worse/unchanged/invalid 是相位变化；矩阵变化另看 matrix_delta。无效值为空，formal_verdict始终空。

GET `/api/v1/channel-assets/mpdb-projects/budget-comparisons/{UUID}/report.zip` 或 points.csv。24小时过期404。422输入无效或同源不匹配；503组件缺失；504计算超时；502状态无效。

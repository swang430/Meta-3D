## 2. 必须优先完成的范围

沿用现有 PC 编号，下面是各项目的 CAICT 最小切片，不增加一条并行 WIP。每片以既有设计/计划、TDD、比例验证、内审、Codex 外审、合并/同步/清理流程交付。

| 顺序 | 归属 | 本批最小交付 | 非现场可以完成 | 必须现场/外部确认 |
|---|---|---|---|---|
| 1 | **PC-01A/B** 配置范围 | 固定当前 LabProfile、mode、32 条链与逐链端口/极化/器件，说明变更影响 | 盘点保存/绑定/解析差异，复用 resolver 做范围快照与缺口展示；暂不做多实验室并行或模板平台 | 对照真实接线、序列号、CE 输出与参考位置，确认实际使用链集合 |
| 2 | **PC-02A/B** 方法与参考量 | 首先把 FSVA 标量功率、源输出参考面、参考天线/接收线缆、PA 和修正账目定义清楚 | 核对 FSVA3000 对应手册的结果单位/单次测量/错误消费；补齐方法选择及拒绝原因；审计带符号公式与不确定度，未经方法批准不改量值定义 | 可用 SA 与有效参考资料，线缆实测/证书、天线适用数据、动态范围及方法负责人批准 |
| 3 | **PC-03A/B** F64 状态 | 确认当前仿真的 Auto/User alignment、In/Out loss、频率/端口与增益状态 | 复用现有状态载体与类型化证据；不支持或空回复保留 unknown | P1-2 同机复验，确认固件/许可和状态可读；缺所需状态证据时先取得厂商方法，不盲发查询 |
| 4 | **PC-04A/B** 真测路损 | 当前一个经确认工作点、明确参考位置、全部所需链及两极化完成原始采集、重复测量、独立检查和清理 | 修正方法入口、逐链来源/符号、量值记录、不确定度预算及清理失败处置；复用已有服务与作业 lease | 在批准功率/接线下取得实际数据；PA 线性和输出范围需验证；不能一个探头或一个频点代表全部链/频段 |
| 5 | **PC-05A/B** 适用与应用 | 本次校准按真实链、频率/带宽、源/接收与对齐状态选择，冻结后实际应用且不重复补偿 | 共用选择/拒绝/冻结/应用投影，明确旧记录策略；补偿只在指定层出现一次 | 用 PC-04 真实记录验证换口/换频仅提醒复核、重校准由操作员判断；独立已证不适用/厂家状态失效仍按原规则拒绝，核对实际应用值 |
| 6 | **PC-07A/B 的最小审计切片** | 第一份校准后的真实执行报告能还原原始值、修正、应用、范围、来源与未确认项 | 复用现有 P2-88～93 报告章节，不等待完整 PC-06 工作台；PC-07 的强依赖是 PC-04A/05A | 使用同次真实执行与原始校准资料审阅；系统资格与外部认可另按既有门验收 |

## 3. 为什么这些要先做

1. **参考测量当前不可用**：SA 停用、接收线缆修正缺失、无真实校准记录，优先解这组前置。
2. **现公式尚需方法裁决**：`ProbePathLossCalibrationService._real_path_loss_measurement_via_ce_sa` 使用 CE 请求功率、天线增益与接收线缆修正，并对结果取绝对值；当前不确定度为采样标准差加固定 0.3 dB。它们是现实现，不是完整可溯源模型。PA 链出现净增益时不能用绝对值抹掉符号，也不能把请求值等同源实测。
3. **单位与测量终态是正式读数前置**：`RealRsFsvaDriver.measure_channel_power` 将返回标量直接解释为 dBm；现调用未显式核对结果单位。对应手册列有 dBm、dBm/Hz 等结果单位及单次同步前置，须在 PC-02 中确认使用模式，明确单位和错误队列证据，再支撑真实校准。
4. **F64 设置会改变修正解释**：内部 alignment、In/Out loss、增益/输入控制必须与软件账目一起记录；避免设备内和软件重复计入同一项。
5. **数据采集与应用需要一起完成**：只生成路损表还不足以让正式测试有可信补偿；至少交付 PC-05 与 PC-07 的最小链，才能在执行/报告中核对。

首个工作点由实际 TestCase/资产与现场方法确认；不能按用例名称或硬编码数字猜频率。CW 点的结果只先覆盖获证范围，扩到其它频点/20 MHz 宽带/其它 RAT 前另验频响、带宽/功率与插值方法。

## 4. 后排、条件项与 HOLD

| 范围 | 安排与原因 |
|---|---|
| 完整 PC-06 工作台、多实验室复用体验 | 最小入口够用后后排，先取得可用实测量与真实应用证据 |
| PC-08 标准 PDP/多普勒/相关性独立验证 | 只在目标方法明确需要时作为其前置；不是每次幅度路损测量都要先通过的总门 |
| 每探头暗室路径相干相位/PWS | 当前 PFS power-only 不将此列入首批；CE 内部与基站输入流对齐仍按厂商及所用方法独立核验。P1-5 保持退出当前队列 |
| PC-09 方向图/静区激活 | HOLD 的真实激活保持；厂商合格方向图可按现有来源门使用。真实场质量若是目标方法的正式要求，必须在该正式范围交付前单独完成；中心点路损不证明直径 2 m 静区已合格 |
| PC-10、新 CE、多实例并行、TRP/TIS 扩域 | 按实际需求/设备/方法条件另立切片，保持原 HOLD，不占本轮 CAICT 最小校准 WIP |
| 无实际 LNA/双工器的校准 | 当前保存配置无这些器件，不默认安排；现场若确实存在则重估该方法范围和必要校准 |

## 5. 资料核对与证据边界

- F64 User Reference Rev 10.2：§4.3.4、§11.3.3、§17.5～17.5.1。本轮 NotebookLM 回答再次经本地 PDF 文本核对：Auto alignment 关机失效、匹配频率/端口，User/Auto 对应值叠加，In/Out loss 定义设备外部链段。采用章节定位，工具页码存在冲突，不直接沿用。
- 输入相位 AN Rev 1.7 §1：作用于 BSE 输出信号流相位差；该证据不覆盖整条暗室辐射链。
- NotebookLM 对“仅做增益即可保证功率分配”的扩展推论未作为验收结论。PFS 项目范围采用既有 `docs/features/calibration/pfs-phase-immunity.md` 与获批方法；不能由手册未提到某前置推导所有正式方法都无此要求。
- FSVA3000/FSV3000 User Manual `1178.8520.02─16`：印刷页 167 说明绝对功率与功率密度；p883–884 的功率结果读取要求完成单次测量并同步；p940–941 的结果单位区分。这里只记录方法审计需求，未新增或运行命令。

数据库只读盘点与代码审计可在非现场完成；参考件与真实量值链、F64 状态及 32 条物理链验收仍为现场/资料条件。下一开发片仍从 PC-01A 的 CAICT 最小范围设计/计划开始。

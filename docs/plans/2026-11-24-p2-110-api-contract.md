## 上传和配置
POST `/api/v1/channel-assets/mpdb-projects/purpose-evaluations`，multipart：
- `archive`：108/109相同的原始 MPDB 外层ZIP，根目录 `R0B0S0D.mpdb`，≤256 MiB。
- `members`：同源成员NPZ，≤32 MiB；固定成员，不重聚簇。
- `asc`：可选已有传导八路H系数ASC压缩包，≤256 MiB；八条文件位于ZIP根目录，采用108的解析、来源校验、源帧恢复和CE误差计算。上传后新增真实候选 `existing-asc`，不是历史范围说明。
- `bandwidth_mhz=100`：有限正数≤10000；`points=41`：3..257奇数；`amplitude_floor=1e-8`：有限正数。
- `selection_start=0,selection_end=25,holdout_start=26`；`holdout_end`可省略，省略时取实际可用共同源帧的末帧（无ASC按原始源帧，有ASC按实际恢复范围与原始源帧交集）；闭区间，两个非空、连续相邻、不重叠的原始源帧区间。缺源帧先拒绝，不扫描后补。
- `objective=phase|matrix`，默认phase；`mode=conducted|ota`，默认conducted。
- `tap_budget_max=31`：1..31；`matrix_nmse_p95_max=1`：有限非负数；`phase_error_p95_max_deg=60`：0..180。
- `manual_candidate` 可空，或 `independent-24/26/31,shared-24/26/31` 六个完整ID之一，或 `existing-asc`（必须上传ASC）。

先冻结来源SHA256、连续源帧计划、预算和误差阈值，再计算。无ASC时候选为109六组，使用0–37；上传ASC后新增第七候选existing-asc，真实样本共同可对齐范围0–36，所有候选在同一冻结范围选择与留出复核，37单列且不参与共同范围排序。若配置包含ASC不可对齐帧，返回422，不静默删帧或填0。工作台不复制CE的分拆、频响、误差或选参算法。ASC来源哈希、恢复时间依据、时延零点、幅度舍入及适用源帧来自108实际计算。H是原始复系数列名，不证明水平极化；时间与时延零点未核验。

## 返回值
200 JSON：顶层 `schema=mpdb-purpose/1`；`status=selected|no_candidate_meets_constraints`；`comparison_id`；`download_url`、`points_url`（均已含/api/v1）；`source.archive/members`、`mpdb_sha256`；`frame_ids`、`source_frame_count`；`common_frame_ids`（无ASC为0–37，有ASC为0–36）；`evaluation`。
所有报告 `formal_verdict=null,hardware_verified=false,alignment_status=unverified,simulated=false`；这是离线实样计算，不能显示成实机或认证通过。

`evaluation` 原样来自CE，schema为 `candidate-evaluation/1`：
- `plan` 含冻结配置；`plan_fingerprint`、`selection_input_fingerprint`、`selection_fingerprint` 为SHA256。留出误差不参与选择指纹。
- `provenance` 上传ASC时增加 `asc_sha256`，`existing_asc_reference.applicable_frames/unmatched_frames/time_basis/delay_zero_basis/polarization_basis/amplitude_roundoff` 来自实际108恢复。ASC没有同策略未拆簇基线，delta不适用，不可把空计数解读为没有退化。
- `provenance` 含原始MPDB、成员及上传包哈希、方法、频偏、端口顺序/端口对、幅度下限、载频、极化与时间/零点依据。
- `candidate_parameters` 各候选策略和请求预算；`selection` 六候选（上传ASC时七候选）仅选择集的统计。
- `selected_candidate`：仅按选择集约束和目标排序；无候选达标为null，`holdout=null`，不回退到“最好但不达标”的方案。
- `holdout`：冻结建议方案的留出报告，不输出全部候选留出排名。
- `manual_candidate` 与 `manual_holdout`：操作员指定及其独立留出结果；不覆盖推荐，不会变成达标建议。
- `excluded_source_frame_review`（顶层）：有ASC时单列源帧37，existing_asc=null、fixed_member_methods保留109六组描述值；不参与选参，不伪造第37帧ASC误差。
- `unmatched_frame_review`：当有建议或人工选择且留出包含37时，单报37帧；不证明ASC参考存在。
- 每组统计含 `frames,missing_frames,actual_taps_min/max,changes_against_same_strategy_baseline`；`matrix_nmse` 和 `phase_error_deg` 各含 `valid,total,coverage,p95,worst`。worst含 `frame_id,offset_hz,value`，相位另有 `port_pair`（port_order索引）；矩阵是八路整体矩阵误差，不是单端口误差。
- 缺失/无效点保留覆盖率；预定点必须完整有效才允许达标建议；无有效误差为null，不补0。
- `ota_status=unverified`（OTA模式缺场参考）；传导为 `not_evaluated`。两模式分别建报告。
- `automatic_adoption=false`；`threshold_scope`明确“本次示例约束，不是认证标准”。

预算为模型复杂度代价；局部收益/退化取CE同策略未拆簇基线的逐点delta计数。不可宣称增预算必然改善。

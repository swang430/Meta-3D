## 发起比较
`POST /api/v1/channel-assets/mpdb-projects/comparisons`，multipart/form-data：
- `archive` 必选：原始 MPDB 外层 ZIP，根目录含 R0B0S0D.mpdb，≤256 MiB。
- `asc` 必选：已有传导 ASC ZIP，根目录恰好八份 `R0B0S0D_TX{0..3}_RX{0..1}_H.asc`，≤256 MiB。允许附 manifest.json。
- `members` 必选：同源 members.npz，≤32 MiB。按同 LINK_ID、源行顺序筛选非零 H 后对应标签，不重新聚簇。
- `bandwidth_mhz` 默认100，0<值≤10000；`points` 默认41，3..257奇数；`amplitude_floor` 默认1e-8，有限正数。

200 JSON包含：
- `schema: mpdb-comparison/1`、`comparison_id`、`download_url`（完整ZIP）、`points_url`（逐点CSV）。URL已含 `/api/v1`，直接作为下载链接。
- `status: partial | unverified`；`formal_verdict:null`、`alignment_status:unverified`、`simulated:false`、`hardware_verified:false`。不可渲染为正式通过。
- `source` 含 archive/asc/members SHA256，`mpdb_sha256`、`carrier_hz`、`polarization:H`、`tap_budget:24`、`offsets_hz`、`amplitude_floor`、`port_order`、`port_pairs`。
- `source_frame_count`、`unmatched_source_frames`：真实38帧样本前37帧恢复，末帧37单列。
- `coverage`：phase_valid/phase_total/phase_fraction、matrix_valid/matrix_total/matrix_fraction。分母保留全部源帧，包括未配对末帧；共同相位掩码要求参考和两方案该端口对均高于同一幅度下限。
- `summary.Lauraycs` 与 `summary.Meta-3D`：matrix_nmse_median、matrix_nmse_p95、phase_error_p95_deg；无有效点为null，禁止当0。
- `message`、`member_row_order`：操作员说明。
- `polarization_basis`：原始 H 列说明和原始极化模式；ASC 仅由 _H.asc 文件名绑定，独立极化来源未核验，status=unverified。H 是系数列名，不能解读为水平极化。

完整ZIP含 summary.json、report.json、points.csv。report.json额外含 `frames`：逐帧CE比较结果、time_basis/delay_zero_basis、左右外推差异、载频相对误差、used_taps及raw/members/asc各8端口power。
power：carrier_coherent_gain=|Σh|²，tap_power_sum=Σ|h|²；无输入参考input_power_w及absolute_received_power_w为null。复系数不是dBm。

CSV列：frame,method,offset_hz,port_a,port_b,matrix_nmse,phase_error_deg,phase_valid,alignment_status,formal_verdict。port_a/b为port_order中的0..7索引；无效数值为空。矩阵误差为线性比值；相位误差绝对值0..180度。

下载 `GET /api/v1/channel-assets/mpdb-projects/comparisons/{UUID}/report.zip` 或 `/points.csv`；有效24小时，过期404。

错误：422参数或来源不匹配/文件无效/无法唯一恢复源帧；503组件缺失；504计算超时；502结果格式无效。错误体 `detail` 为中文。

# P2-103 工作台轨迹时间、输出更新率和聚簇来源

## 操作员需要知道什么

**射线分组不是输入 MPDB 的必备附件。** 以 RT-IMT-2030 为例，MPDB 保存许多传播路径；如果要把这些路径归并成每帧最多 24 个抽头，就必须知道哪些路径相加。“成员表”只是这份分组清单的一个保存格式（NPZ）。早先在做[八路传导的三方频谱对照](../evidence/imt-three/README.md)时，离线脚本先把每一帧的参考链路分组，再按时延、收发角度给其他链路的射线分配组号。它是当时计算得到的中间结果，不是原始测量，不证明同组射线来自同一个物理反射体。复用它的好处是能重现同一组结果，不需要为这份样本再运行一次 HyperRT。它不是 OTA 的输入要求。

**帧编号不是秒，输出更新率也不是车速。** 两帧之间的参考接收阵元位移除以经过时间，得到这一段的平均移动速度；不能从两个位置恢复区段内任意时刻的速度。有原始时间时保留非均匀间隔；没有时间时即便已知位置，也不能自动判定这段是快行、慢行还是停留。操作员给出的时间或速度必须标为播放假设，不作为原场景事实，不能据此改写原始多普勒。

**更新率单独决定输出的时间网格。** 一辆车变速时，等时间间隔的输出样点在空间上可以疏密不同。历史页面中的 171.18765176762867 Hz 也见于这批样本另一个已导出 ASC 的文件头；它不是这份原始 MPDB 中提取出的更新率，不能静默继承。离线生成与仪器播放是两项验收，本项只做前者。

### Task 1: 从原始文件到生成清单的一致实现

# S5c 上下行聚簇文件核验与精度评估设计

基于 Meta-3D 10b2ca2a。原始 ZIP 的 SHA-256 与 S5a 解析记录一致。上下行各 38 个 LINK_ID，逐组对照原始帧记录与质量表，76 组的编号及原始路径数全部吻合。两个方向均为每组 24 个簇。采用 S5a 按距离与 5 m/s 推导的时间轴，总时长 36.174939 秒。

## 本片验收

1. 用方向和 LINK_ID 关联三个输入（原始帧、簇表、质量表），校验唯一性、覆盖、路径数、簇数、有限值和时间顺序。缺行、重复或单位依据不足时记录具体影响。
2. 核对导出表达式 H2PL、H2ANG、时延与角度单位的源码依据，再从功率损耗和相位恢复复响应。沿用已有天线响应，核实角度坐标。
3. 复用现有离线指标，按帧比较功率、时延分布、角度和复频响，单列跨帧变化、质量指标出处及无法评价项。提交逐帧结果和可复算命令。本批覆盖 24 簇，8、16 簇需各自的原生结果。报告给出误差分布，正式用途容限另据批准方法判定。
4. 先以错帧、缺行、相位和单位错误验证测试能抓到故障，再跑原样本、独立内审和 GitHub 两轮外审。评估完成后再决定正式多快照接入。此片不涉及仪器命令，NotebookLM 不适用。

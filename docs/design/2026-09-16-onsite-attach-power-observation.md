# Cell ON 后功率观察窗口设计

## 可观察故障

当前 CMW500/F64 现场链路在 CMW500 Cell ON 之前读取 F64 输入功率。真实执行中得到
`[None, None]` 与 `No input signal detected`，但手动输入参考配置仍被记录成成功；Cell ON 后
又直接开始 60 秒 UE attach 计时，操作员没有时间查看功率和 F64 `.smu` 端口拓扑。

## 已批准方案

1. 在 `MIMOOTAConfiguration` 增加 `attach_power_observation_s`，默认 `0` 秒，允许范围
   `0..300` 秒。默认值不增加等待；现场用例可显式配置 60 秒。
   （2026-09-18 更正：默认 0 秒**不等于**行为不变 —— 具备该能力的基站 + F64 每次执行都会多一轮只读采样，
   且第 6 条的严格门在默认配置下同样生效，即 attach 之前多了一道 fail-closed 门。）
2. CMW500 明确到达 `ON,ADJUSTED` 后、UE attach 计时开始前，调用一次上层观察回调。
   观察时间不计入既有 attach timeout。
3. 回调使用仓内已有、已有出处的能力读取：
   - CMW500 当前配置的 RS-EPRE 回读；
   - F64 `get_metrics()` 返回的活动输入、输出、逻辑通道、拓扑来源、输入功率和输出功率。
   不增加或猜测任何 SCPI。
4. 观察开始时采样一次；配置了等待时间时保持 RF 状态，每秒检查执行取消，等待结束后再采样
   一次。随后才进入完整的 UE attach 60 秒计时。
5. 采样结果写入本次执行结果载荷并输出结构化应用日志。日志明确区分：CMW 配置回读、F64
   实测输入、F64 实测输出，以及 `.smu` 冻结拓扑；不把配置值称为实际射频输出。
6. `precheck_strict_input_level=true` 时，任何活动 F64 输入口缺测或非有限数值均在 attach 前
   fail-closed；false 时只留黄色诊断并继续。

## 非目标

- 不增加全局暂停/恢复状态、人工“继续”按钮或新的数据库真值。
- 不推算 DUT 接收功率、路径损耗或 CMW 实际射频输出。
- 不改变正式 provenance 白名单，不让未知或模拟值进入正式 KPI。
- 不处理 Aerotech `PFBK(Y)` 单轴错误；它是另一个已记录的现场发现。

## 验收标准

- 回调严格发生在 CMW500 `ON,ADJUSTED` 后且 attach 计时前。
- 配置 60 秒时，日志可见开始/结束两组功率与同一 `.smu` 拓扑，且 attach 仍获得完整 60 秒。
- 严格模式下 `[None, None]` 不再被当作成功，首个 attach 状态查询前即停止。
- 配置 0 秒时只增加一次只读观察，不增加等待。
- 所有新增行为由可回退变异的定点测试保护。

## 已知局限（2026-09-18 过审时补记）

- 严格门判的是「活动输入口有没有读到有限数值」，不是「有没有信号」。真机上无输入信号的读数是一个很低的
  有限值（09-16 执行 `f8f5fd90` 输入口 2 为 −108.0 dBm），不是空值；要判有无信号须换到带该语义的查询并有
  PROPSIM 手册出处，不凭一次观察值加阈值。观察结果的放行状态因此叫 `recorded`，不叫「通过」。
- 只有实现了配置功率回读的基站驱动（今天只有 CMW500）配 F64 才接线；其它组合下
  `attach_power_observation_s` 填了也不生效，GUI 字段说明里已写明是 CMW500。

# PC-01A：CAICT 校准配置盘点与变更复核

## 已批准方向与本片边界

承接实验室配置与校准整体设计及 CAICT 优先级评估，扩展既有 LabWorkspace 总览。
当前故障：只能看到链路数量，不能还原逐链配置，也不能比较配置变化。
本片只读；不连接仪器、不保存配置、不复制证书、不判断校准可复用或正式资格。
PC-01B 的实物序列号、接线、参考位置和全部链现场确认保持未验。

## 权威关系及完整影响面

| 生产入口 | 权威来源 | 消费方 | 可观察断言 |
|---|---|---|---|
| GET calibration-scope | 显式 LabProfile → chamber；原 RF resolver → 当前模式链 | LabOverview 配置盘点卡 | 展示相同逐链端口/极化，而非重新解析另一套链 |
| POST calibration-scope/compare（只读） | 当前服务器重新取数；用户 baseline 仅为比较输入 | 总览“比较配置变化” | 改端口/器件/几何/资源声明提示复核；改名不变 |
| response schema | 独立 Pydantic 模型 | live OpenAPI / YAML / generated TS / 手写类型 / service | 四镜像一致，GUI 不计算摘要与变更 |

快照按白名单记录：lab/chamber/mode 身份、暗室几何与组件声明、绑定资源和当前保存资源身份、当前模式拓扑及逐链映射、Probe 保存声明。
不导出凭据、自由备注、任意 connection_params、校准结果或当前证书。
数据库 UUID/端点不代表实物身份；明确 physical_identity=unverified，量值均为声明。
原 resolver 的 cable_loss_db 仅作历史配置字段，不解释为本片取得的校准。
本片不改变原 resolver 与校准消费者，比较也不写入正式适用性真值。

## 比较与状态

面向操作员统一称“配置”，不用“范围”指代保存配置。标题为“校准配置盘点”，按钮为“重新读取配置 / 保留配置快照 / 比较配置变化”；读取/暂停/失败/无差异提示及明细使用同一术语。重新读取只更新页面保存配置，不连接仪器、不验证实际接线；比较仍由服务器读取当前配置，不要求先手动读取。内部 calibration-scope 路由/字段名保持兼容，频率范围和校准适用范围等专业概念不改。

规范 JSON 排序后 SHA256；名称、备注、时间戳和列表顺序不影响摘要。
baseline 必须符合版本、结构和自身摘要；拒绝损坏输入，不用 baseline 授予任何权限。
实验室/暗室/模式/几何/资源/Probe声明及全局拓扑身份/所需仪器变化保守要求所有新旧链复核；逐链端口/极化/损耗及其拓扑镜像不扩大成全部链。活动节点/边声明变化按同一有向连接的下游链定位；无法关联的差异保守复核全部链。器件参数按安全白名单展示，未知自由参数只保留摘要，不导出秘密字段。
链缺失、重复身份、resolver warnings 保持缺口，不显示“校准合格”。
GUI 保留快照只在当前 lab 页面生命周期有效；切换实验室重新挂载清除；请求失败/暂停/刷新中不展示旧结果为新成功。

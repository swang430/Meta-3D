# 八路传导多普勒谱离线对照

输入为同批下行 MPDB 及 Lauraycs 八份传导 ASC。复算采用各阵元对的 CHANNEL.H（含收发天线响应）、DELAY 和 DOPPLER；用两侧源帧分别按射线频移推进，在帧间平滑混合。只比较共同的 6188 个输出时刻，采样率取文件头 171.18765176762867 Hz。各端口均计算载频及 ±50 MHz 处的复信号。两侧采用同一组 256 点 Hann 窗，双边谱分辨间隔约 0.669 Hz。符号约定经正负单音测试。所有对照均为软件间相对比较。

| 载频处端口 | 谱峰 Hz（原始 / 重建） | 均方根谱宽 Hz（原始 / 重建） | 归一化功率谱重叠 | 总功率差 dB（重建相对原始） |
|---|---:|---:|---:|---:|
| TX0 → RX0 | -6.02 / -6.02 | 3.76 / 4.84 | 80.2% | -0.20 |
| TX0 → RX1 | -5.35 / -6.02 | 10.27 / 4.74 | 48.7% | -0.23 |
| TX1 → RX0 | -6.02 / -6.02 | 3.90 / 4.80 | 76.0% | -0.52 |
| TX1 → RX1 | -5.35 / -6.02 | 6.78 / 4.73 | 66.7% | -1.65 |
| TX2 → RX0 | -6.02 / -6.02 | 6.73 / 4.77 | 67.4% | -1.44 |
| TX2 → RX1 | -5.35 / -6.02 | 6.70 / 4.69 | 68.3% | -1.16 |
| TX3 → RX0 | -6.02 / -6.02 | 6.72 / 4.77 | 66.7% | -1.57 |
| TX3 → RX1 | -6.02 / -6.02 | 7.11 / 4.70 | 66.5% | -0.96 |

谱重叠为两个单位总功率谱逐频格取较小值后求和，100% 表示形状完全一致。表中总功率差独立保留。八路主峰方向一致，但 TX0 → RX1 的原始谱宽超过重建值两倍，峰值接近不足以说明谱形一致。未预设合格阈值。

距离估算轴按帧间距离除以 5 米/秒建立。另以第 0～36 帧每秒一次、末帧维持距离估算末点作敏感性对照，八路三个频点的谱重叠变化最大为 0.31 个百分点。这只衡量所选两种时间假设的影响。真实时间误差、两种算法各自的误差和现场频谱均未独立测得。输出谱的奈奎斯特区间内可以检查功率分布，但本实验不能排除原始 ASC 在采样前已经发生混叠。

[八路谱图](eight-port-spectra.png)及[逐频格数值](spectra.json)含本次输出；JSON 还包含正负频移的功率占比和运动频带以外的功率占比。复算命令为 `python3 scripts/imt_conducted_spectrum.py RT-IMT-2030 输出.json`，依赖 NumPy。本批对照不能验证 128 路暗室空间场。

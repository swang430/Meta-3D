# 从测试用例执行下行四发二收传导工程

使用 RT-IMT-2030 的八份传导 ASC，在隔离数据库保存 MIMO_OTA 用例，从用例库执行接口启动。基站、信道仿真器和转台均为模拟驱动。用例选择 external_asc，asc_source_path 指向八份 ASC 和 manifest.json 所在目录，asc_manifest_sha256 固定为 2b085a23350abd08b84476bdf6f7874dc034e6a8eb980aa2ca393324488c1f2e。

模拟执行逐路核对文件摘要、响应数量、更新率和抽头数据。八路均有 6188 个响应，各 24 个抽头，更新率 171.18765176762867 Hz。索引从零算起，末样点 6187 对应 36.1416254976 秒。这个数表示文件首末响应的间隔。模拟游标由模拟驱动成功启动后的单调时钟换算；实际仪器回读保持空值。

用例经过时间包括准备与收尾。本批的已有 ASC 与原始射线对照可对齐源帧 0–36，源帧 37 超出 ASC 范围。参见[同预算比较与留出范围](../../plans/2026-11-24-p2-110-api-contract.md)。文件没有原始 38 帧的绝对时刻。执行记录分别保存清单摘要、文件样点和模拟位置；设备实际末帧仍待现场核对。

现场须另外取得与八路文件对应的设备可播放工程和端口映射，确认实际加载版本、播放起止及末帧。此模拟用例不开放真机加载。

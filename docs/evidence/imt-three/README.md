# 八条传导链路的三方多普勒谱

比较同一批 2.565 GHz 下行数据的三种表示：Lauraycs 原始逐端口 ASC、MPDB 逐射线复算和使用 ChannelEgine P1-83 归并函数的联合聚簇复算。覆盖 38 个位置、4 发 × 2 收、载频和 ±50 MHz，共 24 组。逐射线和联合聚簇使用相同距离时间轴及帧间混合，三方使用同样的 6188 个输出时刻、256 点 Hann 窗和双边频率格。

| 发 → 收 | 均方根谱宽 Hz（原始 / 射线 / 联合） | 原始与射线重叠 | 原始与联合重叠 | 射线与联合重叠 |
|---|---:|---:|---:|---:|
| 0 → 0 | 3.76 / 4.84 / 3.82 | 80.2% | 78.0% | 94.0% |
| 0 → 1 | 10.27 / 4.74 / 3.64 | 48.7% | 48.9% | 93.4% |
| 1 → 0 | 3.90 / 4.80 / 3.76 | 76.0% | 73.4% | 93.6% |
| 1 → 1 | 6.78 / 4.73 / 3.59 | 66.7% | 69.3% | 93.1% |
| 2 → 0 | 6.73 / 4.77 / 3.83 | 67.4% | 70.9% | 94.4% |
| 2 → 1 | 6.70 / 4.69 / 3.64 | 68.3% | 70.2% | 94.2% |
| 3 → 0 | 6.72 / 4.77 / 3.75 | 66.7% | 71.6% | 92.4% |
| 3 → 1 | 7.11 / 4.70 / 3.57 | 66.5% | 66.5% | 92.9% |

每个位置在 TX0 → RX0 归为 24 簇，其他阵元按与参考射线的时延及收发角度最近者继承成员编号。按既有原型使用 ns 和度的欧氏距离；成员关系是几何推断，不能证明物理射线身份。每个端口分别相干合并复系数，按功率求代表时延和代表多普勒。各簇用单一代表频移推进，未合成簇内多普勒展宽；不同位置之间仍采用两端复场平滑混合。第 0 帧四发到 RX0 的成员分区已与旧原型逐射线核对，相同分区允许编号不同。

八路载频处联合模型的谱宽均低于逐射线模型。最大分歧仍在 TX0 → RX1，该链路在联合归并之前就与原始 ASC 存在明显差异。不同端口对原始 ASC 的谱重叠有升有降。本对照没有原场景密采样真值，没有给出谁更接近现场的判决；八条单路功率谱也不能验证跨端口相位或 OTA 辐射场。

复算使用 NumPy 和 ChannelEgine main 的 reduce_link 函数。将 ChannelEgine 根目录加入 PYTHONPATH 后，从 Meta-3D 根目录运行：

```sh
python3 scripts/imt_joint_spectrum.py RT-IMT-2030 docs/evidence/imt-three/members.npz /tmp/three-spectra.json
```

成员表由脚本 scripts/imt_joint_members.py 从原始下行 MPDB 生成，使用 RT_22 发布版的 HyperRT 运行环境及其弧度接口，种子 20261121。复算频谱可直接使用保存的成员表。

# 完整链路模拟校准

这是软件演练，不是暗室实测、VNA校准或正式证书。结果不能采用到真实执行补偿或正式KPI。真实F64自动采集暂未开放：还须核对已加载场景、全部受影响输出及本次启动授权，旧安全确认不能替代这些条件。

## 准备接线与模型

在“仪器资源”核对实际驱动；参与采集的仪器须全部为模拟驱动。仅把保存策略写成模拟不足以证明当前实际驱动身份，服务器会再次核对。

在独立拓扑副本中保存完整链路：

`F64输出 → 发射线缆 → PA → 发射线缆 → Probe → 空气段 → SGH参考天线 → 接收线缆 → FSVA`

发射线缆可以是独立器件，也可以是CE→PA及PA→Probe的两条连接；同一物理段只声明一次。参考段须明确保存空气段、参考天线、接收线缆和分析仪目录关联。SGH接FSVA与接VNA是互斥的接线阶段，不假设同一物理端口同时连接两台仪器。

通过普通器件属性或连线编辑，勾选“为此段声明模拟模型（非实测）”，填写适用频率及合成损耗／增益。线缆和空气段填损耗，PA、探头及SGH填增益。它们是人为选择的模型参数，独立于标称值和校准值；不自动把缺值填零，也不从证书取值。当前每段模型声明一个频点，采集频率必须匹配；换频率须明确修改并保存模型。不得把模拟参数当作实物计量依据。

## 采集与审阅

在“通路校准”的单项入口或批清单中选择“按完整链路模型模拟（非实测）”。它与自备样本／CSV模式互斥。选择保存路径、填写频率、请求功率、样本数及参考位置；单项确认后直接开始；批清单先预览，再明确开始。批次有人工步骤时，仍须逐项核对并继续，不能把模拟当作取消流程保护的理由。

模型模式不用手填接收线损。服务器先形成独立的模拟接收线缆观测记录，保存线缆身份、频率、两端参考面、合成功率及计算式，然后由完整路径引用。该过程没有操作真实VNA。完整路径中，F64及FSVA走共同控制事务；模拟通信检查当前端口、频率、功率和运行状态，不是仅列出命令预览。

计算关系为：

`通路净损耗 = 源端前后功率均值 −（分析仪接收功率 + 接收线缆损耗）`

接收线缆只去嵌一次。结果详情及CSV保留关联记录、公式和模拟来源；错误、超时、取消或清理未确认应显示失败／未知，不应伪装成成功。模拟清理结束仅表示软件流程完成，不能证明真机已停止射频输出。

“模拟演练样本”／CSV仍接受操作员自备合成样本，用于重放与计算检查。旧线损文字仍只是声明，不会自动变成新线缆校准记录，也不计入完整模型演练验收。

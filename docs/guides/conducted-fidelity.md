# 在信道工作台核对传导工程

从 MPDB 创建传导工程后，工作台从实际写出的每条 ASC 回读抽头，按同一源帧、相同频偏和同一源时延原点，对照聚簇前的复系数。替换了端口天线时，基准使用替换后的逐射线结果。工程包中的 conducted-fidelity.json 记录逐帧、逐链路的复误差和幅度最低点，以及误差最大的端口对与频偏。

分析使用带内均匀分布的 33 个频点。已有功率参考提供带宽时使用该带宽，缺少带宽时使用明确标注的 20 MHz 离线分析范围。最低点只在这些频点中查找。相对相位比较采用共用发射端或接收端的链路；任一幅度不超过 1e-12 时只统计复误差，并记录相位剔除数。

可在同源功率参考 JSON 中提供 tx_spectral_covariance，填写实际发射端口顺序 tx_ports，单位 unit 为 mW/Hz，frequency_model 为 flat_over_band，real 与 imag 分别给出复矩阵实部与虚部。功率以相同矩阵在两条曲线上逐频计算，按平坦谱解析积分，计入射线之间的相干项。缺少矩阵或端口参考依据时，接收功率显示未核验。

结果仅用于离线分析。缺少共同相位和时延原点时，仅作文件数值比较。现有候选分析仅适用于原始四发两收和原始天线响应；其他端口配置或替换天线的工程标为候选比较未核验。需要选择更换时延或增加抽头时，从工程师离线分析进入已有的候选方案比较，先选定容差与留出路段，再核对增加的抽头以及改善和变差的位置。软件保留原始工程，采纳由操作员决定。

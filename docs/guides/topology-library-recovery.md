# 可恢复拓扑库与独立 PA 操作指南

适用：PC-04A-5a～5d 及 PC-04A-7 软件入口。以下步骤由新隔离 SQLite、全绑定 Mock 的真实 API/浏览器旅程核验；不代表实物导通、真实停发、采用资格、校准认证或现场 B/HOLD 通过。逐分支依据见[5d 验证摘要](../validation/2026-10-29-pc04a5d-topology-acceptance.md)与[启停验证摘要](../validation/2026-10-29-pc04a7-topology-activation.md)，器件细节见[器件声明指南](topology-device-contract.md)。本指南不授权改动用户原 CAICT 图。

用户既有落地点仅作定位：原图 `87df2355-00f2-4fd6-9a38-ebacb2ccb2e5`，5c PA 副本 `f5883b11-f7ae-462c-acb1-a42062e51711`，既有部署回执记为 r2、非活跃、非默认。5d 没有更新这两图，也没有新做备份、恢复 PostgreSQL 或重启服务。仓库依据是 [PR547](https://github.com/swang430/Meta-3D/pull/547)及[5c 验证](../validation/2026-10-28-pc04a5c-independent-pa.md)；`output/pc04a5c-deployment.md` 是执行机器本机资料，不是公开下载地址，当前状态不得由旧回执推定。

## 1. 先核对 Lab、暗室、开关及图短 ID

在当前 LabProfile 选择器选实验室；进入“射频开关矩阵拓扑”，核“当前暗室”与“射频开关设备”，再在“拓扑库（仅编辑选择）”选图。核对名称、短 UUID、当前保存修订，不仅凭同名判断。原图只读核查，后续编辑在明确副本进行。

成功回读：重载后暗室、开关和图 ID 与目标相同；“刷新拓扑库”可重新读取列表。Lab A 与 A共享若绑定同一 chamber，会看见同一数据，不是按 Lab 隔离图记录；浏览器偏好仍按 Lab/开关分别保存。

拒绝与保守恢复：未绑定暗室不能加载；不同 chamber 的显式越界请求拒绝 409；dirty/在途/未知状态会阻止范围切换。先核 Lab 关联及目标 ID，等待已确认终态，或按第 4/6 段处理草稿；不要绕过守卫把甲图写到乙范围。迟到回包不应夺取新范围选择。

## 2. 复制已保存图，再明确命名

无未保存草稿时，点击“复制已保存版本为…”；核对弹窗源图短 ID，填写“拓扑名称”→“确认复制”。副本保存后可用“重命名”→“确认命名”修改名称；空白名不可提交，首尾空白会 trim。

成功回读：副本有新 UUID、r1，`is_active=false`、`is_default=false`；命名后修订递增，重载显示新名。复制只取服务器已保存内容，不复制草稿、旧采用记录、证书或历史执行；已有内嵌 calibrated loss/phase 键清为 null，原来缺键的不补造。name-only 保存不改变执行选图所用 `updated_at`。原图、历史和 Lab 绑定应保持。

拒绝与保守恢复：草稿、采集/写请求在途或结果未知时不能复制/命名。写结果不确定先用“核查服务器最新拓扑库（只读）”核是否已有副本及修订，不能因没有成功提示就重复复制。核对后才点“确认采用服务器最新并结束核查”；“保留输入，取消”不采用、不重发。

## 3. 本浏览器默认，不是正式执行选择

选中副本后点击“设为本浏览器默认编辑图”。这只保存当前浏览器、Lab 和开关范围的编辑偏好，不激活图、不改默认图字段、不改仪器绑定，也不为正式测试选择副本。

成功回读：同浏览器重载会自动选回该 UUID；仍可清洁切回原图。独立浏览器 context 没有此偏好；A/A共享 chamber 的 Lab 偏好各自独立。正式消费者仍按服务器既有 chamber/active/updated_at 规则选图。

拒绝与保守恢复：dirty/busy/未知时先解决未落定工作；默认选项失效时刷新库并重新核目标 ID，不把 localStorage 偏好当执行绑定证据。改变启用状态必须走下面独立确认，不由选择图或设置偏好触发。

### 3.1 显式启用与停用：会影响后续正式选图

先核对目标 Lab、暗室、开关、图名与 ID。库中“已启用／已停用”表示服务器保存的 `is_active`，不表示有无未保存草稿，也不表示校准合格。无草稿和未结束操作时，点击“启用拓扑”或“停用拓扑”；确认弹窗核对图名、完整 UUID、目标状态和基线修订，再明确确认。取消不发写请求。

正式 MIMO 执行保留原规则：从**同暗室全部启用图**中按 `updated_at` 倒序取首图，不限定于当前开关库，也不读取本浏览器编辑偏好。启用更新本图时间，可能改变后续执行选图；停用可能改选另一启用图，或没有启用图。不会自动停用其他图，不改默认字段、图内容、仪器绑定或既有历史；启停会正常新增保存修订，不改历史原件。已有启用图的内容保存也可能更新其时间，本片没有改选择规则。路径校准仍显式传目标 `topology_id`，停用图被拒绝；启用只是必要条件，不授予校准、采集、认证资格。

成功回读：确认后等待写入及服务器列表／详情 GET 均成功，再看状态与修订；重载应保持该图状态。未保存、保存中、采集中或结束未知时均不可启停，弹窗打开后变忙也必须等待。写入失败不显示成功；409 或结果未知先点“核查服务器最新拓扑库（只读）”，比较状态、修订和历史，再明确“确认采用服务器最新并结束核查”。GET 或取消核查不解除未知锁，不自动重发。沿用第 6 节跨 SPA 边界，不能借离页当作取消或安全解锁。

## 4. “应用”、保存与放弃草稿分开

在合法声明的副本中，器件属性用“应用器件修改”，连线用“应用修改”；这时只改本地草稿。看到“拓扑草稿未保存”后，点击“保存拓扑”才发服务器写入。关闭尚未应用的抽屉不等于保存。

成功回读：保存后服务器 revision 递增，重新加载同 UUID 仍有相同标签、位置、端点及模式引用。若只想撤销未保存改动，点击“放弃未保存改动”，取消原生确认应保留 dirty；明确确认仅回到当前图已知保存快照，无写请求、不增修订，不是恢复历史。

拒绝与保守恢复：dirty 时库/category/命名/复制及 Lab 切换受守卫保护；422 应看端口、内部 pair、模式引用等具体原因，不清掉保护或改原图凑保存。5d D03 使用合法 PA 副本；raw 旧图缺 ports 的保存能力不在该成功结论内。保存成功也不等于可执行：CE 身份矛盾可能被保存为草稿，但正式完整通路消费者会明确拒绝。

## 5. 误保存后，恢复合法修订为新修订

先保存或显式放弃当前草稿，点击“保存修订历史”，选目标 rN，查看“历史原件（raw，只读）”及当时状态；点击“预览恢复差异”。核历史原件、将写入候选、当前差异及警告后，勾选“确认将此历史声明恢复为新的保存修订”→“恢复为新修订”。

成功回读：隔离演练为 copy r1→合法候选 r2→位置保存 r3→预览 r2（零写）→恢复为 r4；当前三个 raw 数组等 r2，r1～r3 原件保留，active/default 不变。恢复清空已有内嵌校准值，不恢复旧采用、证书或执行资格。后续真实操作会继续增修订；本片浏览器 PA 最终为 r9，不能把演练 r4 当最终状态。

拒绝与保守恢复：r1 原件可以读取，但 raw 源缺 F64/probe ports，preview/restore 均应 422、无写入，不能承诺任意旧修订可恢复。选已合法声明的修订；没有合法修订时停止并核查声明来源，不能改历史原件补 ports。过期 expected_revision 返回 409、缺令牌返回 422；按第 6 段只读核对后重新预览，不自动重试。

## 6. 409、数据库写未知：先只读核查，再显式采用

双页面并发时，甲保存新修订后，乙旧令牌保存应 409。乙草稿和输入应保留；点“刷新查看服务器最新”打开“核对服务器最新保存修订”，逐项比较本地令牌、服务器详情、历史操作与保留草稿。点“保留草稿，取消核对”不覆盖；只有“确认放弃旧草稿并采用服务器最新”才放弃旧草稿。

成功回读：核查 GET 本身无写、不自动采用、不解除 unknown，也不重发 save/restore。采用后重新读取和预览，再决定是否有必要写入；历史与当前 revision 可定位真正落库结果。

拒绝与保守恢复：请求可能已经落库但回包/后续 GET 失败时，不能称失败零写，不能靠重复点击赌结果。组件内 unknown 持续阻止编辑/写入，仍可见的按钮也可能由 handler 拦截。真实在途写的 beginWork 跨 SPA 卸载守住 Lab，直到请求落定；数据库 unknown/dirty 不承诺跨 SPA 持久，离页重入会重新 GET 服务器基线而不自动重试。需要保留旧草稿时先停在本页核查；不要利用导航当作安全解除。采集 unknown 的锁不同，见下一段。

## 7. 独立 PA：映射、未知量、单次补偿与采集锁

在明确副本中核 CE 原 B1～B32 → 各 PA.in → PA.out → 原 probe/pin/极化。PA 声明 in/input、out/output、唯一有向 in→out；外线用真实端口拖接，保存后重载核端点和模式引用。B1/B16/B32 的 UI 抽样不能代替全 32 路机器映射。方向错误、反 pair、缺一侧边应拒绝，先在副本修合法闭包，不动原 CAICT。

成功回读：新两边 loss 为 null、长度仍缺键；未知保持空，不填 0。旧 20 dB 只是来源未核的 PA 标称；旧 0.8 dB/5 m 只在 opaque 留档，不能无依据分摊两侧或当当前补偿，PA 不是线缆 owner。path/末边/matrix compensation 未知仍为 null；已知零独立为 0。整链 confirmed 在真实适用消费者中只能使用一次，不再加标称20、两侧线损或旧内嵌99。5d 的28仅为显式 synthetic 已存历史消费者样例，不是新实测或新采用成功。

采集仅在具备资格的独立声明通路操作；inactive 的32路副本/端口练习图不能借小图成功冒称可采集。“开始自动采集”或“取消采集并停止本次单音”在途、GET未知或结束未确认时，不编辑/切 Lab/恢复；恢复网络后点“读取历史／恢复采集状态”，必要时“重读本次记录”，显式读取服务器终态。5d 已观察两轮不同 run 的 running、软件租约释放与重入，第三 run 只补 Lab/恢复守卫。Mock 历史“确认采用此实测记录”禁用，确认 API 拒绝；samples=[]、net_loss=null、cleanup_confirmed=null、F64 control release 未知。软件 simulated/cancelled 不是实物停发证据，真实 cleanup_unconfirmed/interrupted、正式报告下载、现场 B/HOLD 仍未验。

本指南不嵌入本机未跟踪截图，避免新检出破图。截图均为隔离 Mock 软件观察，原件与失败索引位置见[已跟踪 Task2 回执](../../.superpowers/sdd/2026-10-29-pc04a5d-topology-acceptance/task-2-report.md)；远程读者需要另行取得证据包，不能把本机路径当下载链接。

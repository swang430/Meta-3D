# 射频拓扑大画布与自动排版

进入「实验室配置 → 射频拓扑」，先核对当前 LabProfile、开关和图名称。库选择仅影响编辑，不改变正式执行绑定。

1. 普通页面的拓扑与校准共用编辑框按原窗口可用高度的3倍展开，整页可以向下滚动；校准内容仍可在侧栏内滚动。点击「专注编辑」改用窗口内可用空间；「退出专注编辑」返回普通长画布。专注不是3倍高度承诺，不会自动收起校准侧栏，也不会覆盖已有辅助区显隐选择。窗口调整不清空草稿。
2. 「收起辅助区」隐藏器件工具、说明和采集侧栏；「展开辅助区」恢复。侧栏只是隐藏，不卸载，不能据隐藏推断采集已结束。
3. 「展开校准面板」可独立放大校准面板，即使辅助区已收起仍可使用；顶部「返回拓扑与校准」返回原布局及原显隐选择，再按需退出专注。展开、返回均保留同一面板、输入、草稿和在途请求；内容可滚动，取消采集入口仍在面板内。这些显示操作不保存拓扑、不启动或停止采集。
4. 「自动排版」主动整理当前共享图的全部节点位置，包括当前模式隐藏的节点。它按实际 source/target 分层、按端口自然顺序组织支路，并为器件、端口与线缆标签留白；不会猜真实 RF 方向或修改 pins、参数、接线、模式、补偿及绑定。打开图不会自动重排。
5. 「撤回本次排版」只恢复最近一次排版前的位置，保留之后的属性和接线编辑；不复活已删除器件，也不删除后来新增的器件。连续两次排版只保留第二次之前的位置。保存开始、采用服务器最新、放弃草稿或换图后，旧撤回失效。
6. 排版仍是未保存草稿。点击「保存拓扑」才沿现有修订链提交；409 保留草稿，网络失败保持未知锁，请展开辅助区显式核对服务器最新修订，不自动重发。已保存版本恢复仍使用「保存修订历史」，不是排版撤回。

大图的「定位全图」是鸟瞰，不保证一屏看清全部文字。用滚轮或缩放按钮放大，拖动画布到目标支路，点击线缆本体编辑。复杂分支、回路和多模式共享图不承诺零交叉。长端口列表会增加节点显示高度，但不新增设备能力。

保存、图库写入、采集未结束或结果未知时，排版与撤回沿用原编辑锁；专注/辅助区切换只是视图操作，不解除锁、不停止硬件。跨 SPA 页面离开的既有边界没有扩展为持久草稿系统。

本功能仅改善编辑显示，不表示接线已接好、仪器已同步、采集可采用、校准合格或现场 B/HOLD 已解除。软件验证见[自动排版验证摘要](../validation/2026-10-29-pc04a6-topology-layout.md)与[编辑空间验证摘要](../validation/2026-11-01-pc04a9-calibration-workspace.md)。

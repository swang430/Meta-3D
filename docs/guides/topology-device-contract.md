# 射频拓扑器件声明操作指南

适用：PC04A4a～4e 当前软件。以下操作来自隔离 Mock 浏览器验收，不等于实物端口、RF 导通、停发或计量资格。标称、目录引用、方向、内部 pair、owner 都是应用声明；不能据标称自动补偿。整链 confirmed 只能通过原校准采用入口生效一次，不能再叠加节点增益或线损。未知留空，不填 0。

## 1. 选择 Lab 与原拓扑

在当前 LabProfile 选择器确定实验室，再在射频拓扑的“射频开关设备”选择已有开关。用“器件列表”定位含隐藏器件的原节点；检查当前操作模式和拓扑名称后再改。成功应在保存后重新加载仍看到同一图及修改内容，不以提示条代替回读。Lab 未绑定暗室会拒绝加载；先在实验室配置修正关联。草稿未保存时切 Lab 被阻止，先保存或明确放弃，不把甲实验室的接线写进乙实验室。切开关后旧转换预览不可继续确认。

## 2. 添加器件与目录引用

选择“新增器件类型”→“添加器件”，从“器件列表”打开“器件属性”。填写“器件名称”；适用器件可用“仪器目录关联”引用已有目录，然后“应用器件修改”→“保存拓扑”。重载检查器件 ID、名称和目录引用。目录引用不修改地址/驱动，不代表已绑定或连接。开关槽须关联本图开关类别；错误类别或缺少必要端口会拒绝，核对现有仪器目录和实际端口后修正，不新增一套自动切换配置。

## 3. 标称量与 metadata

器件抽屉按类型显示标称量、来源说明与适用起止频率（MHz）；旧 PA 数值在连线抽屉。填写后“应用器件修改”（连线用“应用修改”）→“保存拓扑”，重载核值、单位、来源、频段。0 是已知零，空值是未知；只改来源/频段不应补出原缺省数值。负衰减、倒序频段等无效输入会禁用应用，修正后再保存。线缆器件不另设第二份损耗，损耗在相邻连线编辑；标称净值只是显示，不是实测或正式采用。

## 4. 物理、逻辑与虚拟端口

在“声明端口”以逗号分隔 ID，点击“应用端口声明”，逐口选择“端口角色”，再“应用器件修改”并保存。基站另外核对“BSE角色”的 dl/ul；逻辑映射不能当物理接头数量。空气段是虚拟端点，不证明硬件接头。unknown 可以保留声明，但不能当双向/可采集能力。重载核端口与方向；若移除仍被外线、内部 pair 或另一模式显式路径引用的口，会拒绝。先合法重接并更新所有引用，再删旧口；不要靠改名称猜方向。

## 5. 内部 pair 与外部连线

PA、衰减器、合路器等在“添加内部通路”后选择“内部输入口”“内部输出口”，应用并保存。画布外线通过真实拖动端口连接；双击连线在“源端口”“目标端口”核绑定后“应用修改”。重载应同时保留内部 pair 和外线，服务器完整路径才是贯通依据；空 pair 不默认全互通。错误方向、同口、缺口或残留引用会拒绝，修正声明和所有模式后重试。开关只沿原 port_maps 和映射身份；在原“仪器管理→射频开关→端口映射配置”核 relay/input/output，不按显示名猜继电器。

## 6. CAICT 旧 PA 与显式转换

用“含旧PA标称的连线”选择精确边 ID（含隐藏/非当前模式）打开旧 PA 参数，不自动创建 PA 节点。确认是原图后改来源/数值、应用、保存并重载核同一边。旧 ce_port/bse_port/sa_port 需要改类型或补声明时，打开“转换旧配置”：选择“转换器件”/“转换连线”，只填有依据的字段，点击“预览转换差异”。检查 before_present、缺键、端口闭包和非目标项；“取消转换”不写入，“确认转换并保存”后重载才算成功。GET 展示默认值不是原 JSON 缺键证据；无依据留空不提交。缺邻接端口或引用冲突时补齐本次合法闭包，不批量改历史模板。

## 7. 同线缆两侧归属、撤销与未知

仅当两条边确为同一物理线缆，在转换面板选“同一物理线缆量值owner原边”，勾选“这两条边表示同一条物理线缆”，预览并确认保存。alias 原值保留但只读，可用“定位owner”检查采用源；撤销选择“显式解组：两侧旧值恢复各自参与”并再次明确确认。重载核归属和原值。跨模式半组、失引用会拒绝，回到完整路径修正，不借全图无关边补数。

隔离输入例：两边各 2 dB，通用路径 4→owner 后 2→撤销后 4；owner 校准值 0 优先，null 保持未知。正式旧 binding 仍只消费末边（alias 仅换源），不能据通用路径总和另加上游损耗。整链 confirmed 仍一次。

## 8. 保存、取消、离线、409、采集锁与历史

抽屉取消/关闭未应用编辑不泄漏；“应用”只改本地草稿，须再“保存拓扑”。保存 pending 时按钮锁定。422 先看具体引用/参数原因、修正草稿再保存；离线保存失败保留草稿，恢复在线后重试并重新加载核落库。转换遇到 409 时输入保留，但旧预览作废，重新“预览转换差异”再确认；受采用历史引用的重导入应拒绝，不删除历史绕保护。

采集时不改拓扑。取消请求没有回执时保持“采集状态未确认结束”锁定，恢复网络读取服务器状态，不靠本地 toast 解锁。本片全 Mock 的 cancelled 终态只证明软件编辑恢复，cleanup_confirmed 与 F64 release 仍 null；真实 cleanup_unconfirmed/interrupted 未验，不得据此确认实物停发。历史参考缺端口/pair 可以在当前 scope/compare 盘点，但路径/采集严格拒绝，盘点成功不授采集资格。历史诊断可查看 JSON；本流程无专属诊断下载入口，客户正式报告下载未验。

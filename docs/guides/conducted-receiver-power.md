# 按接收插口功率准备传导测试

在虚拟路测的传导准备窗口选定场景、工程和拓扑，勾选“按接收插口功率准备”。选择源帧，留空目标沿用场景预测，或填写一处接收口的目标平均功率。整个工程采用同一增益偏移。若多个目标不能用同一偏移达到，工作台指出冲突。

实验室在与工程摘要匹配的登记中填写 receiver_power_evidence，包含 asset_sha256、已审核的预测文件 filename、文件 sha256，以及源接收口到实物插口的对应 source_to_receiver。功率预测采用本工程的带内 ASC 回读积分；仅有相对系数的工程缺少绝对功率依据。当前现场传导执行支持下行四发两收。

末段线损从本次适用的逐路径校准原文读取。例如接收插口目标 −70 dBm、末段损耗 3 dB，仿真器物理连接器目标为 −67 dBm。软件保留预测、设定回读、插口实测三者的来源。PROPSIM 用户手册 Rev10.2 §4.3.4 指出，登记 Out loss 后，设定电平的参考面可能已在线缆末端。因此物理连接器目标不能直接当作设备的电平命令。

正式执行复用已校准并检查过峰值余量的工作点。实验室需将参考帧的插口平均测量原文登记为 reference_measurement，包含文件名和内容摘要。文件需绑定工程、校准原件、预测文件、源帧、带宽、仪器序列号，并逐口记录同时工作的设定值与插口平均实测。载入工程后按既有流程回读设备设定与限值，在已校准的工作点播放。不同目标需选择相应的有效工作点校准。设计数据用于预览；现场重新连接、端口范围、实测接收功率及停发单独验收。

登记中的 manifest_file 指定同源 ASC 清单原件。参考帧测量中的 asc_manifest_sha256 为该清单的摘要；final_cable_compensation 必须记录 physical_connector_target_only，表示末段线损仅在计算物理连接器目标时计入。

参考帧平均测量原件的每个 receiver_ports 条目还须给出该工作点的允许误差 allowed_error_db 和该插口平均功率测量的不确定度 average_uncertainty_db（均为非负 dB）。当实测与目标差值的绝对值加上不确定度不超过允许误差时，插口符合工作点。等于边界时可通过。缺少这两项的原件需补齐后重新登记摘要。各帧的峰值、输出及安全余量仍须独立通过检查。

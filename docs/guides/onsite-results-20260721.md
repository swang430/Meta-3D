## 当天软件实证修复(驱动/流程,已在工作树,待 PR)

1. **F64 幂等怪癖三处**:已停态 GOS / 已在档 STATIC 3→3 / 清位 STATIC 0→0 —— F64 对"重复设当前状态"一律报 `-200`,驱动原样当失败 → 假失败中止。修:GOS/STATIC 3 豁免同签名;STATIC 0(GO 前清直通)先排干再让错误门只看 GO。
2. **UXM set_cell_config 小区重启超时**:OFF→写参→ON 后 `*OPC?` 用默认 5s 超时必炸(重启需 10s+)。修:切 30s 档,完毕恢复。
3. **F64 输入定标顺序机制**:加载 .smu 工程会带入工程内存的输入参考/峰均比(+20/12),冲掉此前设置 → 输入参考必须在加载后下发(= 手动定标参数的正确用法)。
4. **闭环起点 -10 dBm 暴力开局实锤**:UXM 屏幕当场抓到 -14.96 dBm(比 -46 基线热 31 dB)→ 手机被震掉线循环(attach→burst→掉线)。修:测试例参数 `input_loop_initial_dl_power_dbm=-46`。
5. **F64 输出增益 +10** 经参数下发 16 口成功(衰落下链路余量补偿;最终手动工作点等效更高)。
